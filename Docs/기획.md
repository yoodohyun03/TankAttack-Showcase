# 게임 기획 — Frozen Front

> 기획서 1번 "본인이 만들고자 하는 게임 기획"에 옮겨 쓰기 위한 문서입니다.
> 최종 게임 기준으로 정리했고, 개발하면서 바뀐 내용은 맨 아래 "기획 변경 이력"에 있습니다.

## 1. 개요
| 항목 | 내용 |
|---|---|
| 제목 | **Frozen Front** |
| 장르 | 3인칭 탱크 슈팅 · **웨이브 서바이벌** (싱글 플레이) |
| 기반 | 수업의 '탱크 게임' 예제 (Unity 6.5, Built-in 렌더러) |
| 한 줄 소개 | 눈 덮인 산악 전선에 고립된 전차 한 대가, 아군 전차와 함께 점점 강해지는 적 전차 5웨이브와 마지막 보스를 막아 낸다 |

## 2. 스토리
혹한의 산악 전선. 본대와 연락이 끊긴 아군 기갑 분대가 눈보라 속에 고립되었다.
적 기갑 부대가 정찰 전차부터 자주포, 그리고 거대한 지휘 전차(보스)까지 몰려온다.
플레이어는 분대장 전차를 몰고 아군 전차와 함께 전선을 끝까지 지켜야 한다.

## 3. 목표와 승패
- **승리**: 5웨이브를 모두 막고, 마지막 웨이브의 **보스 전차**를 파괴 → 승리 화면
- **패배**: 플레이어 전차의 HP가 0이 되면 → 패배 화면
- 아군 전차가 파괴되어도 패배하지 않음 (웨이브를 클리어하면 증원)

## 4. 조작법
| 입력 | 동작 |
|---|---|
| W / S | 전진 · 후진 |
| A / D | 차체 좌우 회전 |
| 마우스 이동 | 시점 회전 → 포탑과 포신이 화면 중앙 조준점을 따라감 |
| 마우스 왼쪽 | 발사 |
| **마우스 오른쪽 (누르고 있기)** | **정밀 조준** (조준경 시점, 줌, 탄도 자동 보정) |
| 1 / 2 / 3 | 일반탄 / 고폭탄 / 철갑탄 |
| **M** | **전술 지도 열기 → 지도 포격** |
| Esc | **일시정지 메뉴** (계속하기 / 처음으로 / 게임 종료) |

**채점·확인용 단축키** (게임 화면에는 표시하지 않음)
| 키 | 동작 |
|---|---|
| F10 | 즉시 승리: 남은 적을 모두 파괴하고 승리 엔딩으로 |
| F9 | 즉시 패배: 패배 엔딩으로 |
| Intro의 "보스전 바로가기" | 마지막(보스) 웨이브부터 시작 |

## 5. 화면 흐름
```
Intro ──(게임 시작 / Enter)──▶ 전투 ──(5웨이브 + 보스 격파)──▶ 승리
  │                             └──(내 전차 파괴)──────────▶ 패배
  └──(보스전 바로가기: 채점·시연용)──▶ 전투(마지막 웨이브부터)
승리 / 패배 ──(다시하기)──▶ 전투   ──(처음으로)──▶ Intro
전투 중 Esc ──▶ 일시정지 (계속하기 / 처음으로 / 게임 종료)
```

## 6. 게임 요소

### 플레이어 전차
- HP 300, 웨이브를 클리어할 때마다 최대 HP의 30% 회복
- 포신 각도는 위아래 범위가 제한됨 (요구사항: 포신 각도 조절 제한)

### 포탄 3종
| 키 | 포탄 | 데미지 | 재장전 | 특징 |
|---|---|---|---|---|
| 1 | 일반탄 | 20 | 0.8초 | 빠른 연사, 무난함 |
| 2 | 고폭탄 | 25 (반경 12m 범위) | 1.6초 | 몰려 있는 적에게 유리, 멀수록 피해 감소 |
| 3 | 철갑탄 | 50 | 2.5초 | 한 방이 강하고 빠름, 중전차·보스 상대용 |

### 적 전차 3종 + 보스
| 종류 | 외형 | HP | 공격력 | 사거리 | 이동 | 특징 |
|---|---|---|---|---|---|---|
| 정찰형 | 모래색, 작음 | 60 | 5 | 110 | 빠름 | 빠르게 접근해서 자주 쏨 |
| 중전차 | 적갈색, 큼 | 250 | 15 | 90 | 느림 | 단단하고 한 방이 셈 |
| 자주포 | 청회색 | 90 | 20 | 260 | 고정 | **산 중턱에 자리 잡은 고정 포대**, 멀리서 곡사 포격 → **지도 포격으로 처리하기 좋은 대상** |
| **보스** | 검회색, 2배 크기 | 1500 | 30 | 160 | 느림 | 체력 50% 아래에서 **광폭화**: 3연발, 가속 |

- 모든 적은 포물선 공식으로 발사 각도를 계산해서 조준 (명중 오차는 종류별로 다름)
- 적은 플레이어와 아군 중 **가까운 쪽**을 공격

### 아군 전차
- 파란색, 2대 (HP 180, 공격력 12)
- 가까운 적을 찾아 공격하고, 싸울 적이 없으면 플레이어를 따라다님
- 웨이브를 클리어할 때마다 파괴된 아군을 다시 채움(증원)
- 플레이어와 아군끼리는 포탄 데미지가 없음

### 웨이브 (난이도 조절)
| 웨이브 | 정찰형 | 중전차 | 자주포 | 보스 |
|---|---|---|---|---|
| 1 | 3 | - | - | - |
| 2 | 4 | 1 | - | - |
| 3 | 3 | 2 | 1 | - |
| 4 | 4 | 2 | 2 | - |
| 5 | 5 | 3 | 3 | **1** |
- 적은 플레이어 주변 180~240m의 평지에 하나씩 나타남
- 웨이브 사이 5초 휴식

### 아이템 (적 처치 시 40% 확률)
| 아이템 | 효과 |
|---|---|
| HP (초록 십자가) | 체력 80 회복 |
| 속도 (파랑 캡슐) | 10초 동안 이동 속도 1.5배 |
| 공격력 (빨강 구) | 10초 동안 공격력 1.5배 |

## 7. 나만의 기능

### ① 정밀 조준 모드
| | 일반 조준 | 우클릭 정밀 조준 |
|---|---|---|
| 포신 | 조준점을 **직선으로** 겨눔 → 먼 적은 감으로 위를 겨눠야 함 | 조준점에 떨어지도록 **탄도 자동 계산** |
| 시야 | 3인칭, 넓음 | 포탑 위 조준경 시점, **4배 줌**, 좁음 |
| 명중 오차 | 큼 | 작음 |
| 화면 | `+` 조준점 | 빨간 십자선 + 목표까지 거리 |
| 쓰임새 | 가까운 적과 빠른 교전 | 먼 적 저격. 대신 주변이 안 보이는 위험 |

### ② 지도 포격 (배틀그라운드식 전술 지도)
- **M키**로 맵 전체를 위에서 본 전술 지도 열기 (내 전차, 아군, 적, 보스 실시간 표시)
- 지도 **휠로 확대·축소**, **끌어서 이동**, **클릭으로 목표 지정**
- [포격] → 포탑이 목표로 돌고 탄도를 자동 계산해서 **4발 연속 발사** (목표 주변으로 흩어짐)
- 사거리 450m (맵이 약 500m × 500m라 사실상 맵 전체), **쿨타임 25초**
- 앞에 언덕·건물이 있으면 자동으로 **곡사**로 바꿔 넘겨 쏨 (포신도 그 각도까지 올라감)

→ 조준 방식 세 가지가 서로 다른 역할: **일반(직사) / 정밀(보이는 적 탄도 보정) / 지도 포격(보이지 않는 곳까지 자동)**

## 8. 배경과 화면
- **설원 전장**: 눈 덮인 산악 지형과 침엽수, 차가운 조명, 회청색 안개, 눈 내리는 효과
- **전선 기지**: 플레이어 시작 지점 뒤쪽에 흰색 계열 군사 기지(격납고, 차고, 감시탑, 컨테이너, 드럼통, 가로등), 맵 모서리에 감시탑 (Environment models by Tiny Teacup Studio)
- 폭발 이펙트: 포탄 착탄, 전차 파괴
- HUD: 웨이브, 남은 적, HP바, 포탄과 장전바, 지도 포격 상태, 보스 HP바, 화면 밖 적 방향 표시

## 10. 기획 변경 이력
개발하면서 직접 플레이하고 판단해서 바꾼 내용입니다.

| 처음 기획 | 변경 | 이유 |
|---|---|---|
| 사막 배경 (Desert Storm) | **설원 배경** (Frozen Front) | 사막을 고른 학생이 많아 차별화. 수업 예제의 산과 침엽수를 살릴 수 있음 |
| 나만의 기능: 업그레이드 상점 (AI 제안) | **정밀 조준 모드** (직접 제안) | 탱크 게임다운 손맛, 조준 실력이 드러나는 기능 |
| 휠로 포신 상하, 마우스로 좌우 | **조준점 하나로 상하좌우 통합** | 조작이 어렵다는 것을 직접 플레이하며 발견 |
| 정밀 조준과 일반 조준 모두 탄도 자동 계산 | **일반 = 직사, 정밀 = 탄도 보정** | 항상 자동이면 정밀 조준이 의미 없고 너무 쉬워짐 |
| 지도 포격 단발 | **4발 연발 + 쿨타임** | 쿨타임이 있는 만큼 한 번에 확실한 효과 |
| 지도 포격 "사거리 밖" 한계 | 포신 각도 범위 확대 + 사거리 450m 제한 | 각도를 넓히면 해결된다고 직접 제안, 사거리 제한은 게임성으로 활용 |
| 아군 AI 바로 추가 | **필수 요구사항을 먼저** 끝낸 뒤 추가 | 마감 일정 고려 |
| 고정 3인칭 카메라 (수업 예제) | 마우스 시점 카메라 | 차체 방향만 따라가서 조준이 어려웠음 |
| 맵에 작은 언덕 추가 | 시도 후 되돌림 | 너무 울퉁불퉁해지고, 길 찾기가 없는 AI가 걸릴 위험 |
| 2~3웨이브에서 계속 패배 | 플레이어 HP 300, 웨이브 회복, 적 공격력 조정 | 직접 플레이해서 난이도가 너무 높은 것을 발견 |
| - | **보스전 바로가기** 추가 | 교수님이 채점할 때 보스까지 5웨이브를 다 깨지 않아도 되도록 |
| 지형만 설원으로 변경 | **흰색 계열 군사 기지 구조물** 추가 | 과제 안내문의 "지형, 건물 등"과 비교해 건물이 빠진 것을 발견. 설원에서 튀지 않게 흰색 계열로 |
| 아이템이 기본 큐브 | 종류별 모양 + 빛나는 효과 + 둥실둥실 | 완성도가 아쉽다고 판단 |
| 수업 예제의 순간이동식 이동(`Translate`) | **물리 기반 이동** + AI 장애물 회피 | 구조물을 넣은 뒤 전차가 건물을 뚫고 지나가며 하늘로 튀는 버그를 직접 발견 |
| Esc: 마우스 커서 풀기 | **Esc: 일시정지 메뉴** | 빌드 전 점검에서 전투 중 게임을 나갈 방법이 없다는 점을 확인 (채점할 때 불편) |
| - | **채점용 단축키** F10(즉시 승리), F9(즉시 패배) | 엔딩까지 확인하려면 5웨이브와 보스를 다 깨야 해서, 확인과 채점을 빠르게 하도록 |
| 자주포: 평지에서 이동하며 멀리서 포격, 가까이 오면 후진 | **산 중턱 고정 포대** | 지도 포격을 써야 하는 상황을 만들기 위해 (기능과 적 배치를 연결) |

## 11. 아이템 외형
- 종류별 모양(십자가, 캡슐, 구), 스스로 빛나는 머티리얼, 같은 색의 조명, 제자리 회전과 위아래 둥실둥실 움직임으로 눈밭에서도 잘 보이게 함

# 게임 기획 — Frozen Front (가제)

## 컨셉
눈 덮인 산악 전선에 고립된 탱크 한 대가 점점 강해지는 적 탱크 웨이브를 버텨 내는 **웨이브 서바이벌** 게임.
(배경은 원래 사막이었으나, 사막 배경을 고른 학생이 많아 차별화를 위해 설원으로 변경)
요구사항을 모두 채운 뒤 시간이 남으면 마지막 웨이브에 **보스 탱크**(기획안 ③ 요소)를 추가한다.

## 승리 / 패배
- 승리: 5웨이브(보스 추가 시 보스 처치)까지 버티면 승리 → 승리 엔딩 씬
- 패배: 플레이어 탱크 HP가 0이 되면 패배 → 패배 엔딩 씬

## 조작 (초안)
| 입력 | 동작 |
|---|---|
| W/S, A/D (방향키) | 전진·후진, 좌우 회전 |
| 마우스 이동 | 포탑 회전 (지형 기준 조준) |
| ~~마우스 휠~~ | ~~포신 상하 각도~~ → 조준점 하나로 상하좌우 통합 예정 (아래 "조준 방식 개선" 참고) |
| 마우스 왼쪽 | 발사 |
| **마우스 오른쪽 (누르고 있기)** | **정밀 조준 모드** |
| 1 / 2 / 3 | 포탄 종류 변경 |

## 요구사항 매핑
| 요구사항 | 구현 계획 |
|---|---|
| Intro 씬 | 타이틀, 조작법, 목표 설명, 시작 버튼 |
| 배경 변경 | 설원: 기존 산악 지형과 침엽수를 살려 Terrain을 눈 텍스처로 칠하고, 흰 안개·차가운 조명·눈 내리는 파티클, 무료 바위/군사 구조물 에셋 배치 |
| 포신 각도 제한 | ✅ 완료 (`CannonCtrl`) |
| 탱크·포탄 다양화 | 포탄 3종: 일반탄 / 고폭탄(범위 피해) / 철갑탄(고데미지) |
| 적 AI 2종 이상 | 정찰형(빠름, 약함) / 중전차(느림, 단단함, 강함) / 자주포(장거리 포격) |
| 난이도 조절 | 5웨이브, 웨이브마다 적 수와 종류 증가 |
| 아이템 | 적 처치 시 HP 회복 / 이동 속도 / 공격력 아이템 드롭 |
| **나만의 기능** | **정밀 조준 모드 (우클릭 스코프)** |
| Ending 씬 | 승리, 패배 각각 다른 씬 |

## 나만의 기능: 정밀 조준 모드
- **일반 조준**: 지금처럼 3인칭 카메라, 마우스가 가리키는 지형 위치로 포탑이 회전
- **정밀 조준 (우클릭 유지)**
  - 카메라가 포신 근처 조준경 시점으로 전환되고 시야(FOV)가 줌인
  - 화면 중앙에 조준선(크로스헤어) UI 표시
  - 마우스 이동량으로 포탑 좌우와 포신 상하를 직접 조절, 감도를 낮춰 정밀하게
  - 우클릭을 떼면 일반 조준으로 복귀
- 추가 아이디어(시간 남으면): 조준선 거리 표시, 탄도 예측선

## 조준 방식 개선 (예정: 포탄 테스트, 이펙트 임포트 후 바로)
- 마우스 휠로 포신을 올리고 내리는 조작을 없애고, **화면 조준점 하나로 상하좌우를 모두 조준**
- 포탑(좌우)은 지금처럼 조준점 방향으로 회전
- 포신(상하)은 조준 모드에 따라 다르게 (확정: A안)

| | 일반 조준 | 우클릭 정밀 조준 |
|---|---|---|
| 포신 | 조준점을 **직선으로** 겨눔 (탄 낙차 보정 없음) | 조준점에 떨어지도록 **탄도 자동 계산** (`Ballistics`) |
| 시야 | 3인칭, 넓음 | 조준경 시점, 줌인, 좁음 |
| 명중 오차 | 큼 | 작음 |
| 쓰임새 | 가까운 적과 빠른 교전. 먼 적은 플레이어가 감으로 위를 겨눠야 함 | 먼 적 저격. 대신 주변이 안 보이는 위험 |

- 세 가지 조준 방식이 서로 다른 역할: **일반(직사) / 정밀(탄도 계산) / 지도 포격(보이지 않는 곳까지 자동)**
- 어느 경우든 포신 각도는 기존 `CannonCtrl`의 `Mathf.Clamp` 제한을 통과 → 요구사항 "포신 각도 조절(제한)" 유지

## 나만의 기능 2: 지도 포격 (자동 탄도 계산)
- **M키**로 전술 지도 열기: 맵 위의 탑뷰 카메라 화면을 UI에 표시, 내 탱크와 적 위치 실시간 표시
- 지도에서 목표 지점 클릭 → 레이캐스트로 월드 좌표 계산 → **포격 버튼**
- 내 탱크의 포탑이 목표 방향으로 자동 회전하고, **탄도 공식으로 포신 각도를 계산**해서 자동 발사
  - 포탄 초기 속도를 고정(`AddForce` 대신 속도 직접 지정)해야 계산이 정확함
  - 낮은 탄도/높은 탄도 두 해 중 선택 가능 → 높은 탄도로 언덕 너머 목표도 공격
  - 사거리 밖이면 "사거리 밖" 안내
- **연속 포격**: 한 번 요청하면 3~5발을 짧은 간격(약 0.4초)으로 연달아 발사
  - 매 발마다 목표 주변으로 살짝 흩어지게 해서 일정 범위를 덮는 느낌 (움직이는 적도 맞을 가능성)
  - 발 수, 간격, 흩어짐 반경은 Inspector에서 조절
- 쿨타임을 둬서 밸런스 조절 (연발이라 일반 사격보다 길게)
- 지도가 열려 있는 동안 커서 표시, 일반 조준·발사 정지

## 확장 (시간 남으면)
- 마지막 웨이브 보스 탱크: 크기 3배, HP 단계별 패턴 변화, 상단 보스 HP바
- 웨이브 사이 업그레이드 상점
- **아군 AI 탱크** (1~2대): 기존 적 AI(`EnemyTank`)를 진영(team) 개념으로 바꿔 재사용
  - 가장 가까운 적 진영 탱크를 목표로 추적·사격, 적도 아군 탱크를 공격 대상으로 삼음
  - 같은 진영끼리는 데미지 없음 (현재 적끼리 오인 사격 방지 로직을 진영 비교로 일반화)
  - 아군은 파란색 등으로 구분, 화면 표시도 다른 색

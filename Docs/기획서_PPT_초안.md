## 슬라이드 3. 목표와 승패, 화면 흐름
- **승리**: 5웨이브를 막고 마지막 보스 전차를 파괴
- **패배**: 내 전차 HP 0
- 화면 흐름: Intro → 전차 선택 → 전투(5웨이브 + 보스) → 승리 / 패배 → 다시하기 / 처음으로

| | 정밀 조준 모드 | 지도 포격 |
|---|---|---|
| 조작 | 우클릭 유지 | M키 → 지도에서 목표 클릭 → 포격 |

- 📷 정밀 조준 화면, 지도 화면

## 슬라이드 10. 포신 각도 제한 (직접 작성)
- 문제: 수업 코드는 휠 입력만큼 회전을 계속 더해서 포신이 한 바퀴 돎
- 방법: 각도를 변수로 저장 → `Mathf.Clamp`로 범위 제한 → 회전값을 덮어씀
```csharp
currAngle = Mathf.MoveTowards(currAngle, targetAngle, rotSpeed * Time.deltaTime);
currAngle = Mathf.Clamp(currAngle, minAngle, maxAngle);
tr.localRotation = Quaternion.Euler(currAngle, 0.0f, 0.0f);
```
- 포인트: `localEulerAngles.x`는 -10°를 350°로 돌려줘서 Clamp가 깨짐 → 각도를 직접 변수로 관리

## 슬라이드 10-1. 플레이어 전차 3종 (전차 선택)
| 전차 | HP | 속도 | 공격력 | 장전 | 외형 | 성격 |
|---|---|---|---|---|---|---|
| 표준 | 300 | 20 | 1.0배 | 1.0배 | 숲 위장색 | 균형형 |
| 경전차 | 200 | 30 | 0.8배 | 0.7배 | 설원 흰색, 작음 | 치고 빠지기 |
| 중전차 | 450 | 13 | 1.3배 | 1.3배 | 짙은 국방색, 큼 | 돌격형 |
- Intro "게임 시작" → 전차 선택 화면(카드마다 **실제 3D 전차가 회전**) → 출격, 선택은 static 변수로 씬이 바뀌어도 유지

```csharp
public static void ApplyTo(GameObject player)   // 전투 시작 때 선택한 전차 능력치 적용
{
    move.moveSpeed = s.moveSpeed;

    fire.tankDamageScale = s.damageScale;
    fire.tankReloadScale = s.reloadScale;

```

## 슬라이드 11. 탄도 계산 (적 AI, 정밀 조준, 지도 포격 공용)
- 포탄 속도가 정해져 있을 때 목표를 맞히는 발사 각도
- **tanθ = (v² ± √(v⁴ − g(g·x² + 2·y·v²))) / (g·x)**  (+ 곡사, − 직사)
```csharp
float root = v2 * v2 - g * (g * x * x + 2.0f * y * v2);
if (root < 0.0f) return false;   // 사거리 밖
float tanTheta = highArc ? (v2 + Mathf.Sqrt(root)) / (g * x)
                         : (v2 - Mathf.Sqrt(root)) / (g * x);
```

## 슬라이드 12. 적 AI 전차
- 1초마다 **가장 가까운 상대 진영 탱크**를 목표로 → 같은 코드로 적·아군·보스 모두 처리
- 탄도 계산으로 포탑·포신 조준, 명중 오차로 난이도 조절
- 건물 회피(앞쪽 감지 후 트인 방향으로), 끼임 탈출, 보스 광폭화(체력 50% 이하가 되면 3연발, 발사 간격 40% 단축, 이동 속도 1.4배)
```csharp
foreach (TankHealth h in FindObjectsByType<TankHealth>(FindObjectsSortMode.None))
{
    if (h.IsDead || h.team == health.team) continue;   // 죽었거나 같은 편 제외
    float d = (h.transform.position - tr.position).sqrMagnitude;
    if (d < best) { best = d; target = h.transform; }
}
```

## 슬라이드 13. 웨이브 매니저
- 코루틴으로 "소환 → 전멸 대기(`WaitUntil`) → 휴식 → 다음 웨이브"
- 소환 위치 검사: 경사, 높이, 건물, **플레이어까지 가는 길에 산등성이가 없는지**
```csharp
yield return new WaitUntil(() => EnemiesLeft <= 0 || IsGameOver);
```

## 슬라이드 16. 나만의 기능 ② 지도 포격
- 직교 카메라로 맵 전체를 위에서 보여 줌, 클릭 위치에서 Ray를 쏴 지형 좌표 계산
- 쏘기 전에 궤적을 미리 따라가 보고, **중간이 막히면 곡사로 전환** (각도를 정하고 필요한 속도를 역산)
- 포신도 실제 발사 각도까지 올라간 뒤 발사
```csharp
// 정해진 각도로 목표에 떨어지는 속도: v² = g·x² / (2·cos²θ·(x·tanθ − y))
if (Ballistics.IsTrajectoryClear(origin, dir * lobSpeed, target, self))
    SpawnShell(Quaternion.LookRotation(dir), 30.0f, lobSpeed);
```
- 📷 지도 화면, 곡사 포격 장면

## 슬라이드 19. AI 활용 방식
- 기획·판단·테스트는 직접, 복잡한 구현은 AI를 도구로
- **AI 제안을 그대로 쓰지 않은 결정**: 정밀 조준·지도 포격 아이디어, 일반/정밀 역할 분리, 설원 변경, 자주포 산 중턱 배치…
- **AI가 틀린 사례**: 네임스페이스 누락·Unity 6.5에서 막힌 함수로 컴파일 에러, 문서에 하지 않은 작업을 적음 → 직접 확인해서 바로잡음
- 기능마다 직접/AI 구분을 구현노트에 기록, Git으로 기능 단위 관리
- (`Docs/AI활용.md`에서 골라 쓰기)

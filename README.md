# Frozen Front

> 2026년 2학기 **융합게임제작실습Ⅱ 중간고사** 과제 — 수업의 '탱크 게임' 예제를 기반으로 만든 3인칭 탱크 **웨이브 서바이벌** 게임 (Unity 6.5, 싱글 플레이)

눈 덮인 산악 전선에 고립된 전차 한 대가, 아군 전차와 함께 점점 강해지는 적 전차 5웨이브와 마지막 보스를 막아 내는 게임입니다.

## 이 저장소에 대해
- 이 저장소는 **열람용 공개 저장소**입니다. 실제 개발은 비공개 저장소에서 했고, 여기에는 **직접 작성한 코드와 문서만** 개발 기록과 함께 옮겨 두었습니다.
  - 포함: `Assets/02.Scripts`(게임 코드), `Assets/Editor`(에디터 도구), `Docs`(기획·구현노트·AI 활용), `CLAUDE.md`
  - 제외: Asset Store 에셋(라이선스상 원본 재배포 금지), 수업 예제 원본, 씬·프리팹 등 Unity 데이터
  - 그래서 이 저장소만으로는 프로젝트가 열리지 않습니다. **게임 실행은 함께 제출한 실행 파일**로 해 주세요.
- **커밋 기록**은 비공개 저장소의 실제 기록(날짜·순서·코드 변경)을 그대로 유지했고, 열람 편의를 위해 **커밋 메시지만 한국어로 옮겼습니다.**
  - 에셋·씬만 바꾼 커밋은 이 저장소에 남길 파일이 없어 빠졌습니다.
- 전체 프로젝트(비공개 저장소)는 요청하시면 초대해 드리겠습니다.

## 빠른 확인 기능
보스전과 엔딩을 바로 볼 수 있도록 넣은 기능입니다. (게임 화면에는 표시하지 않음)

| 방법 | 동작 |
|---|---|
| Intro 화면 오른쪽 아래 **"보스전 바로가기"** | 마지막(보스) 웨이브부터 시작 |
| 플레이 중 **F10** | 즉시 승리 → 승리 엔딩 |
| 플레이 중 **F9** | 즉시 패배 → 패배 엔딩 |
| 플레이 중 **Esc** | 일시정지 메뉴 (계속하기 / 처음으로 / 게임 종료) |

## 조작법
| 입력 | 동작 |
|---|---|
| W / S, A / D | 전진·후진, 차체 회전 |
| 마우스 | 조준 (포탑과 포신이 화면 중앙 조준점을 따라감) |
| 왼쪽 클릭 | 발사 |
| 오른쪽 클릭 (누르고 있기) | **정밀 조준**: 조준경 시점, 줌, 탄도 자동 보정 |
| 1 / 2 / 3 | 일반탄 / 고폭탄(범위 피해) / 철갑탄(강한 한 방) |
| M | **전술 지도 → 지도 포격** (휠 확대·축소, 끌어서 이동, 클릭으로 목표 지정) |

## 과제 요구사항과 구현
| 요구사항 | 구현 |
|---|---|
| Intro 씬 | 실제 전장을 도는 카메라 배경, 제목, 스토리, 조작법, 포탄 설명, **전차 선택**, 시작·종료·보스전 바로가기 |
| 배경 변경 | 설원 지형, 차가운 조명·안개, 눈 내리는 효과, 흰색 계열 군사 기지 |
| 포신 각도 제한 · 탱크·포탄 다양화 | `Mathf.Clamp` 각도 제한, **플레이어 전차 3종**(표준·경전차·중전차, 3D 미리보기로 선택), 포탄 3종, 아군·보스 전차 |
| 적 AI 2종 이상 | 정찰형 / 중전차 / 자주포(산 중턱 고정 포대) + 보스(광폭화) |
| 난이도 조절 | 5웨이브, 점점 강해지는 구성, 마지막 보스 |
| 아이템 | HP 회복 / 이동 속도 / 공격력 |
| 나만의 기능 | **정밀 조준 모드**, **지도 포격** (막히면 자동 곡사, 쿨타임 10초) |
| 엔딩 씬 | 승리 / 패배 각각 다른 씬, 배경은 전투가 끝난 그 순간의 실제 화면 |

## 개발 방식
- 기획·판단·테스트는 직접 하고, 복잡한 기능의 구현은 AI(Claude Code)를 도구로 활용했습니다.
- 기능마다 **직접 / AI 구분**을 구현노트에 기록했고, AI가 작성한 커밋에는 `Co-Authored-By` 표기가 남아 있습니다.
